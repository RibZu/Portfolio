## Summary

A ground-up visual redesign establishing a single coherent design identity ("Obsidian with Neon Pulse") across all sections except the Hero. The previous redesign (feat 008) produced sections that looked like individually-styled patches. This plan replaces that approach with a **design system first** strategy: two new global tokens, two new global utility classes, one new micro-component, and targeted CSS Module edits that all trace to the same token set.

Key deliverables:
- **Animated bouncing ball** in the navbar (CSS `@keyframes`, no JS)
- **Language switch relocated** from inside the nav pill to a fixed corner element
- **Unified section heading pattern** (label + title + accent underline) across all 4 sections
- **Unified surface/border/accent system** eliminating per-section one-off values
- **Contact section opened up** — gradient card container removed, content on page background
- **Skills terminal harmonised** — out-of-palette green removed, dots redesigned

**Performance Goals**: Lighthouse ≥ 90 all categories; CSS `@keyframes` ball is GPU-composited (`left` property is not — **see note below**)

> **⚠ Performance Note on Ball Animation**: Animating `left` triggers layout/paint on every frame — not GPU-composited. For 60fps, the ball animation should use `transform: translateX()` instead. However, `translateX(100%)` refers to the element's own width. Solution: use a CSS custom property `--ball-travel` computed at the header level, or use `translateX(calc(var(--header-inner-w) - 20px))`. Simpler alternative: animate `margin-left` — also not composited. **Best approach**: Use `transform: translateX()` with `--ball-travel` defined via the header's known width. Since the pill's max-width is 800px, `--ball-travel: calc(min(100vw - 40px, 760px))` covers all viewport sizes. Use `animation-direction: alternate` for cleaner code:
> ```css
> @keyframes ballBounce {
>   from { transform: translateX(10px) translateY(-50%); }
>   to   { transform: translateX(var(--ball-travel)) translateY(-50%); }
> }
> .ball {
>   position: absolute;
>   top: 50%;
>   left: 0;
>   --ball-travel: calc(min(100vw - 60px, 770px));
>   animation: ballBounce 3s ease-in-out infinite alternate;
>   will-change: transform;
> }
> ```
> This is GPU-composited, 60fps on all devices.
