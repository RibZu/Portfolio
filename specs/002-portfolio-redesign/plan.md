# Implementation Plan: Portfolio Redesign

**Branch**: `[002-portfolio-redesign]` | **Date**: 2026-09-21 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/002-portfolio-redesign/spec.md`

## Summary

Complete visual redesign of the portfolio to achieve a minimalist, highly professional look targeted at recruiters. This involves completely removing `react-bootstrap` and `bootstrap`, replacing them with custom CSS Modules, and significantly simplifying the content (e.g., removing verbose technology descriptions) to reduce cognitive load and focus on what matters.

## Technical Context

**Language/Version**: JavaScript (React), HTML, CSS

**Primary Dependencies**: React, Vite (Removing: `react-bootstrap`, `bootstrap`)

**Storage**: N/A

**Testing**: N/A

**Target Platform**: Web (Vercel Static)

**Project Type**: Web Portfolio

**Performance Goals**: Lighthouse > 90, < 200kB initial JS

**Constraints**: Must use existing color tokens, must be minimalist, must remove Bootstrap.

**Scale/Scope**: Single page application redesign.

## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

- **I. Simplicity First**: PASS. Removing Bootstrap simplifies the dependency tree. We are using native CSS Modules instead of a heavy CSS framework.
- **II. Static-First**: PASS. No server-side runtime is introduced.
- **III. Accessible by Default**: PASS. Custom components must maintain focus states and contrast.
- **IV. Performance Budget**: PASS. Removing Bootstrap will significantly reduce the CSS and JS payload, directly aligning with the 200kB budget.
- **V. Verifiable Changes**: PASS. Tested locally before deployment.

*Note: The Constitution currently lists `react-bootstrap` as part of the stack. Removing it is a direct user request to simplify the design and stack (Principle I), which justifies deviating from the previously documented stack.*
